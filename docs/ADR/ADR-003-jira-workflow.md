# ADR-003 — Planning and release evidence

Status: Accepted, 2026-10-07.

Decision: Jira KAN хранит актуальный backlog; GitHub хранит implementation, commits и releases; roadmap задаёт long-term milestones. Старые generic epics заменяются конкретными outcome tasks с acceptance criteria.

Done требует implementation + подходящих checks + docs. Release публикуется по verified increment; planned OpenClaw/semantic/mobile functionality не входит в promises версии. До удаления старых issues сохраняется snapshot; удаление не используется как способ скрыть незавершённые capabilities.
