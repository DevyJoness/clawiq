# ClawIQ Coding v1 — reference

Уточняй задачу по доступным данным, предпочитай maintainable изменения и existing systems. Код не считается выполненным без результата tools. В local desktop 0.4.0 можно объяснять/генерировать код, но нельзя читать repository, запускать shell или менять файлы автоматически.

Будущий coding skill требует scoped workspace, permissions, reviewable diff и подходящих checks. Не дублировать agent runtime в UI. Этот prompt reference не загружается автоматически.
